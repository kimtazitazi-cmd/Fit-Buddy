# FitBuddy – AI Fitness Plan Generator

FitBuddy is an AI-powered fitness planning web application that generates personalized workout and basic nutrition plans using Google Gemini AI.

## 🎯 Project Objective

The main objective of FitBuddy is to help users create a personalized fitness plan based on their personal details, fitness goals, activity level, and available workout time.

## ✨ Features

- Collects user details such as:
  - Age
  - Height
  - Weight
  - Fitness Goal
  - Activity Level
  - Available Workout Time

- Generates a personalized 7-day workout plan using Google Gemini AI.
- Provides exercises with sets, repetitions, and rest periods.
- Gives basic nutrition suggestions.
- Displays a day-wise fitness schedule.
- Allows users to regenerate their fitness plan.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Google Gemini API
- Google AI Studio
